# Ide

Tempat menampung ide-ide mentah sebelum masuk perencanaan.

## Cara tambah ide baru

1. Copy `TEMPLATE-ide.md` menjadi file baru, contoh: `ide-aplikasi-catatan.md`
2. Isi sesuai template
3. Kalau disetujui → pindahkan ke `../perencanaan/roadmap.md`
