# Docs - Perencanaan & Ide

Folder ini untuk perencanaan project ke depan dan penempatan ide-ide.

## Struktur

```
docs/
├── README.md              # Index ini
├── perencanaan/           # Rencana project, roadmap, backlog
│   ├── README.md
│   └── roadmap.md
└── ide/                   # Kumpulan ide mentah, draft, eksplorasi
    ├── README.md
    └── TEMPLATE-ide.md
```

## Cara pakai

1. Tulis ide baru: copy `ide/TEMPLATE-ide.md` jadi `ide/nama-ide.md`
2. Ide yang disetujui → pindahkan ke `perencanaan/roadmap.md` sebagai backlog
3. Update `roadmap.md` tiap ada prioritas baru
