## Getting Started

Requirements:
- Android Studio Ladybug or newer
- JDK 11+
- Android SDK 37

Clone and run:

```bash
git clone https://github.com/NadindraDwiA/BISMILLAH.git
cd BISMILLAH
./gradlew assembleDebug
```

Or open the folder in Android Studio and press Run.
